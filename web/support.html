Using Wordtick in Google Docs

  1. Open a document, then choose Extensions → Wordtick → Open Wordtick.
  2. In the sidebar, press Use selection or Use whole document.
  3. Pick reading aloud or silent reading, and a speed.

Full steps: install in Google Docs · install in Microsoft Word.

Common questions

The selection count shows 0. Highlight text in the document first, then press Use selection again. Text inside images or drawings is not counted.

How do I uninstall? In Google Docs, go to Extensions → Add-ons → Manage add-ons, then remove Wordtick. To revoke access completely, visit myaccount.google.com/permissions.

Does Wordtick change or save my document? No. It only reads the text to count it. See the Privacy Policy.
