wordtick

install in Google Docs

Takes about a minute. You add Wordtick to one Google Doc, and it times your selection or the whole document.

Steps

  1. Open the Google Doc you want to use.

    Sign in with your Google account.

  2. Click Extensions → Apps Script.

    A new tab opens with a file called Code.gs.

  3. Replace everything in Code.gs with this, then press Save. 
    function onOpen(){DocumentApp.getUi().createAddonMenu().addItem('Open Wordtick','show').addToUi()}
function show(){DocumentApp.getUi().showSidebar(HtmlService.createHtmlOutputFromFile('Sidebar').setTitle('Wordtick'))}
function getText(which){
  var d=DocumentApp.getActiveDocument();
  if(which==='all')return d.getBody().getText();
  var s=d.getSelection();if(!s)return'';
  return s.getRangeElements().map(function(e){
    var el=e.getElement();if(!el.editAsText)return'';
    var t=el.asText().getText();
    return e.isPartial()?t.substring(e.getStartOffset(),e.getEndOffsetInclusive()+1):t}).join(' ')}
  4. Click + next to Files, choose HTML, and name it Sidebar. Replace its contents with this, then Save. 
    <!doctype html><html><head><base target="_top"><meta name="viewport" content="width=device-width,initial-scale=1"><link rel="stylesheet" href="https://wordtick.vercel.app/style.css"></head><body><div id="app"></div>
<script src="https://wordtick.vercel.app/core.js"></script>
<script>WP.mount(document.getElementById('app'),{mini:true,source:function(w,set){google.script.run.withSuccessHandler(set).getText(w)}});</script></body></html>
  5. Go back to your Doc and reload the page.

    After a few seconds you'll see Extensions → Wordtick → Open Wordtick.

  6. Click Open Wordtick. The first time, Google asks you to approve it.

    Click Continue, pick your account, then Advanced → Go to Wordtick (unsafe) and Allow. It's marked unsafe only because it hasn't been through Google's review yet. Wordtick only reads the open document to count words, and never edits it.

Want it in another Doc? Repeat these steps, or open your Doc and choose File → Make a copy so the add-on comes with it.
